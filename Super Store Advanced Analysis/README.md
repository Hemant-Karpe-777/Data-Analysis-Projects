# 📦 Global Superstore EDA – Business Insights Project

📊 This project explores the Global Superstore dataset to identify sales trends, customer behavior, and profitability challenges across different countries, categories, and segments.

---

## 🎯 Objective

- Understand what drives profit & loss
- Identify top/bottom customers, countries, and categories
- Translate raw data into strategic business decisions

---

## 🔍 Key Insights

| Insight | Explanation |
|--------|-------------|
| 💸 High Discounts = Low Profit | Deeper discounts negatively affect profit |
| 📦 Tech Wins, Furniture Fails | Technology is most profitable; Furniture least |
| 🌍 Some Countries Always Lose | Certain regions constantly operate at a loss |
| 👤 Customers Vary | Some top buyers yield low/no profit |

---

## 📁 Dataset

- Source: Global Superstore (public)
- Format: CSV (orders, customers, regions, sales, profits)
